- `recent.md` — Most recent activity (default read this).
- `archive-YYYY-Www[letter].md` — Older weekly archives (letter suffix if
  a week was split across multiple files).

Entries are newest-first both across files and within each file. Letter
suffixes are shard ids assigned as a week was split, so the date range —
not the letter — is the authoritative ordering. Archives are kept to a
bounded size (e.g. ~200-250 lines); `recent.md` is rotated into a new
archive once it grows past that ceiling.
